# FoodBridge – Stop Food Waste

## About the Project

FoodBridge is a web-based platform designed to reduce food waste by connecting restaurants, hotels, event organizers and households with NGOs and communities in need.

It aims to make surplus food donation easier and encourage volunteers to participate in food collection and distribution.

## Features

- Responsive homepage with simple navigation
- Food donation form
- Volunteer and partner sections
- Food donation cards with images
- Food category filters
- Sample NGO matching
- Impact calculator
- Interactive tabs and form validation

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage
- Git and GitHub
- Vercel

2. Open the FoodBridge folder in VS Code.
3. Open `index.html` in your browser or use Live Server.
